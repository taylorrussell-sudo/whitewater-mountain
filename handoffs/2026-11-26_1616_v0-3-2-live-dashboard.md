## Changes and decisions

- The loopback service serves the shared dashboard HTML and its private integration script. The static index still runs the six simulated scenarios. Private mode displays ECMWF IFS HRES for seven-day lodge guidance and powder alerts, independent Canadian HRDPS short-range guidance, measured Nelson CS and derived GFS freezing crossings. Forecast inversion comparisons use paired hours from the same model.
- Source details distinguish last checked, last successful check and source valid time. Forecast issue times remain unknown. Stale snapshots stay in SQLite and outside active indicators. An incomplete snowfall window is unavailable. Reported resort snow and measured mountain conditions remain unavailable. Whitewater and Southridge collection stays disabled pending permission.
- A bodyless same-origin POST queues the single scheduler worker and exposes progress. The 60-second global request cooldown lives in the process. Persistent per-source due times and provider controls still govern collection after restart. Healthy Open-Meteo sources can check early after the per-source minimum. Nelson retains its hourly minimum. [Service and API guide](../mountain_service/README.md)
