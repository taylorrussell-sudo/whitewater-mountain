GEM Global is the named forecast candidate at a provisional lodge point and the ECCC Nelson CS reference point. A SQLite JSON snapshot store is sufficient for the proof of concept. ## Remaining bugs, assumptions, data-source and safety limitations

Written Whitewater permissions, supported access method, sensor coordinates and source clocks remain open. Whitewater collection is disabled. BC alternative station availability, precise CSV semantics and licence application remain open. Open-Meteo model issue time is unavailable from the ordinary response contract and observed snowfall cannot be recovered from forecast output or regional depth changes. Live observations are required for source accuracy evaluation and measured inversion comparisons. Avalanche data remains outside v0.3.0.

## Dependencies / security / privacy / backup implications

Python uses its standard library. The demo and tests run offline without live records, credentials or subscriptions. The live probe commands discard payloads. SQLite online backup and restore were verified on the local synthetic database only. Before private deployment, choose permitted retention, verify encrypted backup coverage and run a targeted restore with approved paths and service definitions.
