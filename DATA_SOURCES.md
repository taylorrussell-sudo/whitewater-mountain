- The service uses the same six-feature filter for Nelson CS once per hour. A service probe accepted six readings. Keep up to 48 hours of retrieved observations as an intermittent recent cache, with no GeoMet bulk archive or backfill. Retain the original feature ID, time, station metadata and any provider notice. [MSC GeoMet schema](https://api.weather.gc.ca/collections/swob-realtime/schema?f=html) · [MSC usage policy](https://eccc-msc.github.io/open-data/usage-policy/readme_en/)
- The primary 9 km IFS API documents no pressure-level fields, and the earlier IFS and HRDPS scalar probes returned all null. NOAA GFS 0.25° (`gfs025`) exposes paired pressure-level temperature and geopotential height. The service requests 1000–700 hPa in 25 hPa steps and 650, 600, 550 and 500 hPa at the nearest GFS grid column, with elevation downscaling disabled. It discards at/below-grid-terrain samples and uses only contiguous above-ground brackets. It retains all supported zero crossings and exact-zero layers. No crossing is inferred beyond a bracket or through a missing sample. The terrain mask and sparse layers leave some near-surface crossings unresolved. [GFS API](https://open-meteo.com/en/docs/gfs-api) · [ECMWF API](https://open-meteo.com/en/docs/ecmwf-api)

A same-period comparison fetched 72 scalar values from each of GFS 0.25° and DWD ICON Global. In the 10 matched hours with a single profile crossing, mean absolute separations were about 10 m for GFS and 328 m for ICON. This checks numerical agreement with the same GFS product and samples the variation between models. It leaves terrain accuracy and observed freezing levels unverified. The scalar APIs expose one height per hour and neither serves as a fallback. Synthetic tests verify multiple crossings, exact-zero layers, gaps, below-ground exclusion and the absence of extrapolation. ## Open-Meteo hourly forecasts

- **Permitted for this intended use.** The free API terms cover personal home automation and private non-commercial apps under CC BY 4.0, with limits below 600 calls/minute, 5,000/hour and 10,000/day. Link Open-Meteo beside displayed data, link the licence, identify adaptations such as computed snowfall windows, and carry model credit. The service uses one multipoint request per model every three hours and a separate pressure-profile request every six hours when enabled. Treat 403 as a stop, honour `Retry-After` for 429, and back off on transient failures. There is no paid dependency. [Terms](https://open-meteo.com/en/terms) · [Licence](https://open-meteo.com/en/licence)
- **Documented request.** GET `https://api.open-meteo.com/v1/forecast`, with `models=gem_global`, `timezone=GMT`, `timeformat=unixtime`, `forecast_hours=169` and explicit metric temperature/wind. Target points are lodge **49.443, −117.146, 1,630 m** (approximate base-area point inferred from location references, with sensor coordinates unverified), and Nelson CS **49.491389, −117.305278, 534.9 m**. Request `temperature_2m` (°C), `snowfall` (cm), `wind_speed_10m` (km/h) and `freezing_level_height` (m above sea level). Preserve the returned grid centre separately from the request coordinates and the returned adjustment elevation. GEM Global remains the default for reproducing the original probes. The diagnostic also accepts explicit model selections. [API contract](https://open-meteo.com/en/docs) · [GEM model details](https://open-meteo.com/en/docs/gem-api) · [Base-area map](https://whitewatermountainresort.com/site/assets/files/5309/wh20_master_plan_addendum_2019_final_1.pdf)
- **Times and math.** Documented JSON has parallel time/value arrays and an hourly units object. Snowfall at time `t` is the modeled accumulation for the preceding hour ending at `t`. Accumulate the first complete UTC bins after the next whole-hour boundary, which may omit the remaining fraction of the current hour. The PoC computes 24/48/72-hour totals and the maximum of all 49 complete 24-hour windows starting 0–48 hours from that boundary. A gap or null makes affected totals unavailable. Missing candidates suppress the maximum and ties select the earliest start. The Forecast API's generation duration in milliseconds is request processing time. Exact model issue time is unknown from this contract. Retrieval age detects stale cache, while model-run freshness requires a verified run-level source. [Hourly definitions](https://open-meteo.com/en/docs#hourly_parameter_definition) · [Model update notes](https://open-meteo.com/en/docs/model-updates)
- **Live lodge and valley probes.** Both GEM Global responses returned JSON and 169 matching consecutive Unix-second slots in UTC, with seven-day coverage of temperature, wind and snowfall. Both had all 24/48/72-hour snowfall totals and the complete 72-hour rolling search. The model returned lodge grid centre **49.500, −117.150** at the requested adjustment elevation of **1,630 m** and valley centre **49.500, −117.300** at **534.9 m**. Every tested model returned all-null freezing-level values with unit `undefined`. The adapter accepts this sentinel only for the entirely null freezing-level field. Leave freezing level unavailable pending a validated source or profile calculation. [Probe commands](poc/README.md)

## Private-use validation policy

Prioritize individual numerical observations from Whitewater (snowfall, snowpack, temperature and wind), official public API/feed discovery, source terms and permitted request frequency. Private use reduces redistribution concerns but is not blanket permission to automate collection. Do not copy proprietary narratives, bypass restrictions or collect/display prohibited material. Follow the documented Whitewater factual-measurement decision above. Keep other sources disabled when applicable terms are materially unclear. Evaluate RWDI, cameras and other content separately. Keep live records and raw payloads out of GitHub. Validate model and observation timestamps, attribution, retention and permitted storage; a forecast or model-derived snow amount is never a measured resort report. Request only the minimum needed data, cache conservatively, and stop on access or rate-limit errors.
